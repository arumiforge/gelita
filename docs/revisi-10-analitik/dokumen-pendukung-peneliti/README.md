## Memperbarui PDF

1. Ubah berkas HTML-nya, termasuk tanggal di bagian atas.
2. Buka berkas itu di Chrome atau Chromium, lalu pilih **Cetak → Simpan sebagai PDF**, ukuran A4, dengan *Grafik latar belakang* dicentang.
3. Simpan dengan nama yang sama.
4. Kalau isinya mengubah keputusan, catat di 04.
