# Finish a step

A cloud session ends without warning at the usage limit, so every finished step is closed as if it were the last. Counterpart of `continue-work`. Background: `docs/cloud-sessions.md` → *While working*.

## 1. Tests

- The tests of the change are green: `vendor/bin/phpunit --no-coverage --filter <TestClass>` or one test file.
- The full suite (`vendor/bin/phpunit --no-coverage`, about 7.5 minutes) runs once before a push that changes code or tests since the last full run. One full run at a time; a hook refuses a second one.
- If `.env` is still there from `tools/dev/serve.sh` and a result looks different from CI, remove it and run again.

## 2. Records, in the same push

- **`docs/PROGRESS.md`:** the open items of this work as a checklist a stranger could follow, and this branch's row under *Active branches* (branch, scope, PR number, what was verified and what was not). Touch only this branch's rows.
- **Decision log:** every decision or deviation as a new section at the end of `docs/perombakan-kelas5/CATATAN_IMPLEMENTASI.md` (research revision: `docs/revisi-10-analitik/04_CATATAN_KEPUTUSAN.md`), in English, headed `## Title (date, branch \`name\`)`. End it with what was **not checked**.
- **New concept:** a row in the glossary file that fits (`.claude/rules/glossary*.md`).
- **New pitfall or command:** a line in `CLAUDE.md`.

## 3. Commit and push

- `git var GIT_AUTHOR_IDENT` must say `Arumi Studios <arumiforge@gmail.com>`. If not, set it as `CLAUDE.md` → *Identity and attribution* says.
- English commit message, no attribution lines.
- `git push -u origin <branch>`: the assigned branch, or the branch the owner allowed. Never `main`.

## 4. Pull request

- None open for the branch: create one, ready for review, with a title that says what the branch is for. Open already: bring its description up to date so it covers every commit.
- Remove a "Generated by Claude Code" footer if the GitHub tool added one.
- When the owner says the PR is about to be merged, remove the branch's row from *Active branches* in a last commit.

## 5. Tell the owner

What was run and what was not, what is still open, and which branches they can delete (sessions cannot delete branches).
