# Aset visual

Sumber jalur aktif adalah `../data.json`, bukan daftar nama dalam dokumen lama. Semua jalur entri dihitung dari root katalog. 483 visual utama terdiri dari 431 WebP dan 52 SVG; jumlah berkas fisik lebih besar karena sumber SVG kontrol dan alternatif.

| Folder | Isi |
|---|---|
| `referensi/` | Acuan berkode `reference.*`; reference.01 adalah Jaka bersyal merah |
| `karakter/` | Frame/pose karakter dengan kode `char.*` |
| `latar/` | Adegan dan latar (`Background`) |
| `peta/` | Peta visual |
| `tantangan/` | 45 visual kebutuhan tantangan |
| `pustaka/` | Media materi Pustaka Kedu |
| `logo/` | Logo dan identitas |
| `antarmuka/` | Elemen antarmuka |
| `ikon/` | Ikon aplikasi, wilayah, avatar, dan kontrol |
| `ikon/vektor/` | Sumber SVG kontrol yang hasil utamanya WebP |
| `lencana/` | Lencana |

Pertahankan nama berdasarkan kode slot dan raster WebP. Syal merah hanya untuk Jaka; Mbah Kedu mengikuti reference.02. Media faktual memakai brief dokumenter. Jangan membuat kembali folder karakter tambahan yang dihapus. Tidak ada rekaman audio di folder ini.

Semua visual berstatus sesuai atas keputusan pengguna, bukan audit baru. Untuk aturan lengkap baca [README proyek](../README.md) dan [panduan AI](../docs/AI-GUIDE.md).
