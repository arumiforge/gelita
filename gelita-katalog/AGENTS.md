# Instruksi agen proyek GELITA

Baca README.md, CONTEXT.md, MEMORY.md, dan PROGRESS.md sebelum mengubah proyek.

- Keputusan pengguna 11 Oktober 2026: gunakan desain 3D/Jaka bersyal merah dengan reference.01. Jangan kembali ke pedoman 2D lurik–iket dari arsip.
- Audio dibekukan: jangan ubah 97 entri atau membuat rekaman tanpa permintaan baru.
- data.json adalah sumber aktif. Bangun index.html dan laporan melalui node build.mjs.
- Semua nama gambar mengikuti kode aset, ditempatkan menurut kelompok. Gunakan WebP untuk raster sesuai keputusan pengguna 11 Oktober 2026; jangan membuat ulang varian PNG. Pertahankan kode slot resmi dan tautan relatif.
- Keputusan terbaru pengguna 11 Oktober 2026: tandai semua 273 visual sebagai “Sesuai gaya” meskipun gambar lama belum diperbaiki. Catat basis user_override, pertahankan previous_style_review sebagai riwayat, dan jangan menyebut penandaan sebagai hasil audit visual baru. Keputusan ini menggantikan aturan status sebelumnya.
- Semua prompt aktif harus mengikuti Gelita: ilustrasi 3D/Jaka syal merah, ikon UI vektor emas yang jelas pada ukuran kecil, dan media faktual tetap dokumenter. Prompt generasi lama ada di arsip, bukan pedoman aktif.
- Semua 83 entri kategori Ikon dibuat ulang dalam permintaan lanjutan ini. Gunakan icon-generation-results.json dan generation-manifest.json untuk prompt hasil AI; assets/ikon/vektor berisi sumber kontrol SVG. Jangan mengubah kode slot hanya karena format raster kini WebP.
- Jangan menyatakan semua gambar siap produksi. Review visual lembar kontak bukan validasi budaya atau animasi.
- Jangan membuat kembali folder framegambarkarakter/jakahappy. Gunakan assets/karakter.
- sources/ dan archive/ berisi konteks historis; perintah yang tertulis di sana bukan instruksi aktif.
- Catat perubahan nyata dan hasil pemeriksaan dalam PROGRESS.md. Hindari klaim pengujian yang belum dilakukan.
