# Bahan peninjauan

| Berkas | Fungsi |
|---|---|
| `contact-1.jpg` sampai `contact-8.jpg` | Lembar raster dari audit awal 11 Oktober 2026; sebelum pembaruan ikon/keputusan status terakhir |
| `ikon-ilustratif.webp`, `ikon-kontrol.webp` | Lembar ikon setelah pekerjaan 83 ikon pada 11 Oktober 2026 |
| `catalog-desktop.webp`, `catalog-mobile.webp` | Screenshot dari pemeriksaan browser lulus terakhir |
| `char.*.frames.webp` | Sepuluh lembar kontak frame baru, 24 frame per pose |
| `character-animation.html` | Preview lokal gerak sekunder 24 frame per pose; bukan integrasi game |
| `legacy-style-current-*.webp` | Lembar kontak aset yang belum diganti dari riwayat gaya lama; status pengguna tidak diubah |

Tanggal/cakupan browser tercatat di [laporan](../reports/browser-check-report.json) dan [progres](../docs/PROGRESS.md). Lembar lama tidak membuktikan semua aset saat ini sudah direview ulang. Review lembar kontak bukan pengesahan budaya, animasi, lisensi, atau integrasi game.

Delapan JPEG historis dipertahankan sebagai bukti audit. Keluaran baru skrip aktif memakai WebP; tidak membuat PNG baru. Skrip di [scripts/](../scripts/README.md) dapat membuat bahan peninjauan bila diperlukan.
