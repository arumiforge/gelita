# Arsip proyek — bukan instruksi aktif

Panduan aktif ada di [README proyek](../README.md), [AGENTS.md](../AGENTS.md), dan [docs/](../docs/README.md). Arsip mempertahankan kondisi sebelum perubahan; tanggal, status, dan perintah di isi dokumen lama bukan keadaan/prosedur terbaru.

| Lokasi | Isi dan kegunaan |
|---|---|
| `audio-baseline.json` | Baseline 97 objek audio; **masih dibaca build dan validator**, jangan dihapus/diubah |
| `before-2026-10-11/` | Data, HTML, prompt, ringkasan, README awal; data dipakai validator untuk target ukuran |
| `source-documents/` | Dua dokumen asal yang dahulu juga ada di `sources/` |
| `scripts/` | Migrasi dan revisi/generasi ikon sekali pakai, disimpan untuk sejarah |
| `before-icons-20261011.zip` | Cadangan sebelum 83 ikon diganti; dipakai pembandingan hash |
| `before-resize-20261011T155118391929Z.zip` | Cadangan data dan WebP sebelum resize |
| `inventory-before.csv` | Inventaris asal sebelum pemetaan nama |
| `before-2026-10-12/` | Progres sebelum perapian dokumentasi; riwayat dengan penanda |

Dokumen sumber menyebut aplikasi/backend/workbook yang tidak disertakan dalam paket ini. Tautan relatif di isi historis merujuk repositori asal dan dapat tidak tersedia. HTML lama juga bukan katalog mandiri dengan jalur aset yang masih berlaku. Gunakan hasil aktif di root.

Folder `sources/` dihapus pada 12 Oktober 2026 setelah kedua isinya dibandingkan dengan salinan arsip; bukti sumber tetap dipertahankan di sini. Arsip baseline dan cadangan bukan sampah yang dapat dibuang dalam perapian rutin.
